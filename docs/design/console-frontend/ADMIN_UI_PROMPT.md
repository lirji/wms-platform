# WMS 管理后台页面提示词

融合两份《WMS仓储管理系统后台UI强约束》后的**唯一准绳**。后续创建或改管理后台页面，先读本文，再写代码。

这不是建议，是强制约束。不允许自行发挥第二套视觉。

本仓库额外约束（优先于模板里尚未落地的能力）：

- 业主件只有 **Ant Design 6 + `@ant-design/icons`**。不引入第二套组件库或 Icon 混用。
- 数据只走已发布公开契约。页面不写死仓库、SKU、库存。不发明 OpenAPI 没有的字段、状态、批量写、页码权威。
- 列表分页是**游标**（首页 / 下一页）。可右对齐、可写「本页 N 条」。禁止把本页条数假装成 `1 2 3 4 5` 或伪造总页数。
- 建单与作业命令用居中 `Modal`。Drawer 只给只读快览（门禁、流水、日志），有公开 GET 才做。
- 模板里的波次、复核中心、异常中心、报表、策略规则器、库位树：契约没有就不要造页面。
- Token 写在 `wms-console/src/design/tokens.ts` 与 `tokens.css`，禁止页面再 Hardcode 一套色。

---

## 0. 生成前必须先做

1. 识别业务域：入库 / 出库 / 库存 / 盘点 / 主数据 / 履约 / 任务 / 对账 / PDA。
2. 识别页面类型：`LIST` `DETAIL` `CREATE` `EDIT` `TASK` `DASHBOARD` `MASTER_DATA` `CONFIG` `EXCEPTION` `REPORT`。对不上就停，不要硬套。
3. 选下面对应模板。缺契约的块标「不做」而不是编造。
4. 明确本页 **唯一 Primary Action**。
5. 状态映射到五类语义 Tag，不自配色。
6. 危险操作走 Danger + 二次确认。
7. 复用已有公共件，禁止页面私有皮肤。
8. 写完用文末清单自检。

---

## 1. 产品定位

企业级 B 端 WMS：高信息密度、高操作效率、克制、工业仓储、SaaS 后台。

禁止：消费端 APP、C 端商城、漂亮大屏、营销渐变墙。

目标顺序：效率 → 清晰 → 一致性 → 异常可识别 → 操作安全。

更漂亮但更慢、更炫但更难懂、更简但藏关键数据：都不要。

浅色后台。

| --- | --- |

| 内容 / 卡片 / 侧栏 / 顶栏 | `#FFFFFF` |
| 主文字 | `#1D2129` |
| 次级文字 | `#4E5969` |
| 辅助文字 / 详情 Label | `#86909C` |
| 禁用文字 | `#C9CDD4` |
| 边框 | `#E5E6EB` |
| 浅分割 | `#F2F3F5` |
| 主色 / 处理中 / 链接 | `#1677FF` |
| Primary Hover | `#4096FF` |
| Primary Active | `#0958D9` |
| Primary 浅底 / 选中行 / 选中菜单 | `#E6F4FF` |
| 成功（数字/进度完成，不当按钮） | `#52C41A` |
| 警告（数字/等待提醒，不当按钮） | `#FAAD14` |
| 危险 | `#FF4D4F` |
| Default 边框 | `#D9D9D9` |
| 表头底 | `#FAFAFA` |
| 行 Hover | `#F5F9FF` |
| Disabled 底 / 字 / 边 | `#F5F5F5` / `#BFBFBF` / `#D9D9D9` |

禁止：大面积渐变、毛玻璃、霓虹、大量投影、高饱和撞色、超大圆角、拟物、每个按钮一种颜色、紫/粉/青当业务语义。

尺寸：

- 控件高 32px（Button / Input / Select / DatePicker / 下拉触发）。主表单区可用 40px，同一区域禁止大量混用。
- 圆角：按钮/输入 6px，卡片/Modal 8px，Tag 4px。禁止 12px 以上按钮圆角。
- 侧栏宽 220，收起 64；菜单项高 40；顶栏 56。
- 表行高 44–48，默认 46。禁止 60+。
- 字号：正文 14，辅助 12–13，Section 16/600，页标题 20/600。禁止页标题 28+，禁止正文普遍 16+。
- 间距只许 4 / 8 / 12 / 16 / 20 / 24 / 32。按钮间隙 8，字段/卡片 16，大模块 24。

密度：Middle / Compact。不为移动端牺牲桌面密度。主适配 1440 / 1920，最低 1280。表可横滚，关键列左固定，操作列右固定。

## 3. 按钮（只许 5 类）

1. **Primary**：本区最核心操作。底 `#1677FF`，字白，高 32，padding `0 16px`，字重 500。一区最多 1 个，特殊最多 2 个。禁止 Toolbar 里新增/导入/导出/下载/刷新/打印全是蓝钮。
2. **Default**：重置、返回、导入、导出、打印、下载、关闭、保存草稿、批量、取消、复制。白底、`#1D2129` 字、`#D9D9D9` 边；Hover 字和边变 `#1677FF`，底仍白。禁止灰实心钮。
3. **Text**：表操作列优先。查看/编辑/详情/日志/复制/打印。`#1677FF`，Hover `#4096FF`。禁止每个操作都加边框矩形。正确：`查看 | 编辑 | 更多`。
4. **Danger**：删除、作废、强制关闭、库存清零、撤销/取消任务、强制完成、删库存/库位。默认只许红色 Text `#FF4D4F`。大红实心只出现在确认弹窗的最终确认。
5. **Icon Button**：刷新、设置、列配置、全屏、收起/展开、更多、密度。32×32，透明底，图标 `#4E5969`；Hover 底 `#F2F3F5`、图标 `#1677FF`。必须 Tooltip。禁止「刷新图标 + 蓝色大按钮」同时出现。

Toolbar 直接可见最多 5 个，多的进 Dropdown。表行直接操作最多 3 个，多的进「更多」；Danger 在菜单底，与普通项之间 Divider。

绿/黄只用于状态，不用于常规操作钮。禁止 Success / Warning / Purple / Gradient / Colored Button。

---

## 4. 状态 Tag（只许 5 色）

所有业务状态必须用 Tag，禁止纯文字、禁止页面自配色。`WARNING` 等别名映射到橙色「等待」，**不增加第六种 Tag 色**。

| 语义 | 用途 | 字 | 底 | 边 |
| --- | --- | --- | --- | --- |
| SUCCESS | 完成、已入库/上架/拣货/复核/出库/盘点/审核/生效、ACTIVE、APPLIED | `#389E0D` | `#F6FFED` | `#B7EB8F` |
| PROCESSING | 入库中/上架中/拣货中/出库中/盘点中/执行中、OPEN | `#1677FF` | `#E6F4FF` | `#91CAFF` |
| WAITING | 待处理/待审核/待入库/待分配、DRAFT、PLANNED、ALLOCATED、STALE | `#D48806` | `#FFFBE6` | `#FFE58F` |
| ERROR | 异常、失败、缺货、冻结、HOLD | `#CF1322` | `#FFF1F0` | `#FFA39E` |
| CLOSED | 已关闭/取消/作废/失效/删除 | `#595959` | `#FAFAFA` | `#D9D9D9` |

实现：`wms-console/src/shared/ui/StatusChip.tsx` 的 `statusTone()`。禁止 `status === 1 ? green : blue`。

WMS 异常（库存不足、库位锁定、SKU 冻结、拣货失败、任务超时、库存差异）必须红 Tag 或红 Icon，禁止整页大红。

## 5. 列表、表、查询

**LIST 固定结构**（搜索区与表不得混在同一视觉区块）：

PageHeader → 可选 Status Tabs → SearchForm → Table Card（Toolbar → 可选 BatchBar → Table → Pagination）

SearchForm：白卡片、1px `#E5E6EB`、圆角 8、padding 16。默认最多 4 列；多一行必须展开/收起。右侧固定 `[查询 Primary] [重置 Default]`。只放契约已有筛选，禁止编 20 个条件。

Toolbar 左：标题 + 共 N 条（本页或接口返回的条数，不编造总量）。右：1 个 Primary + Default + Icon（刷新/列设置）。

Table：表头 `#FAFAFA` / `#4E5969` / 14 / 500；正文 `#1D2129`；横向浅分割线，禁止 Excel 重网格。文本/时间左齐，数量/金额右齐，状态左齐或居中，操作列固定右 160–220。单号/SKU 等可详情字段必须是 `#1677FF` 链接，Hover 下划线或 `#4096FF`。长文本 ellipsis + Tooltip。空态用 Empty「暂无数据」，可创建时给主按钮；禁止只写「无」。

分页：表底**右侧**。本仓库用游标「首页 Default / 下一页 Primary（有下一页时）」+「本页 N 条」。请求 `limit` 默认 20，可 20/50/100。禁止居中占一整行，禁止假页码。

Tab：同一业务不同状态切换。未选 `#4E5969`，选中 `#1677FF` + 2px 蓝条。禁止 5 个彩色按钮。异常 Badge 红色。没有状态计数接口就不要编数字。

批量：仅当表已有勾选且契约有批量命令时。勾选后出现 BatchBar：已选择 N 项 + 操作 + 清空选择。底可用 `#E6F4FF`，禁止强蓝底。危险批量必须二次确认。

## 6. 壳层、卡片、详情、弹层

侧栏浅色白底。选中：字 `#1677FF`、底 `#E6F4FF`、左侧 3px 主色条。图标只许灰/蓝，禁止每项彩色 Icon。

顶栏 56、白底、底边 `#E5E6EB`。右侧：仓库切换、权限、用户、头像、退出；有能力再加消息/帮助。禁止巨大 Banner。

Card：白底、8 圆角、1px `#E5E6EB`、padding 16–20、间距 16。禁止默认大阴影。统计卡同样白底浅边；数字 24–28 可用语义色，禁止整块红橙绿紫底。

详情 Label `#86909C`，Value `#1D2129`。页头必须能看到业务状态，例如 `入库单详情 [入库中]`。三级以上要面包屑（13–14px，弱于标题）。

Modal：确认 400–480，普通表单 560–640，复杂 720–960。标题 16/600。Footer 右对齐 `[取消] [确认]`。禁止简单确认用 1000 宽。

Drawer 用于只读快览：快速详情、日志、流水、审批、SKU 信息、任务效果。宽 480 / 640，复杂 720。禁止为简单日志新开整页。

Loading：表用表格 loading；提交钮 loading 且禁用，文案「提交中...」。禁止整页空白。

Disabled：见 Token，cursor `not-allowed`，禁止与正常钮一样。

Error：禁止只打 Console。加载失败「加载失败，请重试」+ 重新加载。业务失败用 Message/Notification，展示可理解原因，禁止统一「系统错误」。

Icon 无文字、缩写、截断、复杂规则、Disabled 原因：必须 Tooltip。

数量：`tabular-nums`，`1,258`。金额 `¥12,580.00`。禁止 `12580.000000`。计划/实收若契约同时返回，必须展示差异；异常差异红色。

时间：`YYYY-MM-DD HH:mm:ss`；仅日期 `YYYY-MM-DD`。禁止同一系统混用 `2026/9/13`、`Sep 13`。

库存若契约有字段，必须区分现存量 / 可用量（重点）/ 预占或锁定 / 冻结，禁止只写「库存数量」。库位编码突出；容量可 `80 / 100`。

进度（有完成数时）：`18 / 30` + 60% + 单色条。正常 Primary，完成 Success，异常 Danger。禁止复杂渐变条。

PDA/扫码：进页自动 focus 输入；成功短绿反馈，失败红反馈并说明原因（SKU 不匹配、库位错误、任务不存在、数量超限）。禁止只写「扫码失败」。

二次确认（必须写清对象和影响）：删除、作废、关任务、库存调整、解锁、取消入出库、强制完成、盘点生效、差异确认。库存调整必须展示调整前 / 增减 / 调整后 / 原因，禁止只输入 `-20`。

Sticky：表头 sticky；关键列左固定、操作列右固定；长表单 Footer sticky；详情页头按需 sticky。

## 7. 页面模板（有能力才套）

### LIST

入库/出库/盘点/移库/库存/SKU/库位等列表。结构见第 5 节。新增在 Toolbar 右且为 Primary。核心单号左固定。

### DETAIL

面包屑 → PageHeader（单号+状态+右侧操作）→ 分组 Sections → 明细 Table → 关联表 → 操作记录（有 GET 才做 Timeline/表）。SKU 明细必须是表，禁止几十个 Form 字段。核心操作在页头右侧。

### CREATE / EDIT

面包屑 → PageHeader → 分组表单（2 列，复杂 2–3 列，长文本整行）→ 明细可编辑表 → 备注 → **Sticky Footer**：`[取消] [保存草稿 Default] [提交 Primary]`。校验在字段下，禁止只 Toast「参数错误」。本仓库创建目前多在居中弹层：弹层内仍分组，Footer 右对齐；不要为了模板改成未批准的整页向导。

### TASK

任务执行页：现在做什么 / 做到哪 / 下一步 / 有无异常。当前库位、SKU、数量大于普通字。本页 Primary 只能是「当前下一步」。异常入口明显但不抢 Primary。

### DASHBOARD

运营工作台，不是大屏。顺序：概览待办 → 异常 → 作业数字 → 趋势（有接口才画）→ 快捷入口。第一屏回答：要处理什么、哪里异常、今天怎样。禁止 80% 面积都是图。数字来自接口行数，不写死。

### MASTER_DATA

有层级且契约支持树才用左树右表（仓→区→位）。否则维持分表 + 点标识进详情。禁止用下拉假装树。

### CONFIG / EXCEPTION / REPORT

仅当公开契约有策略、异常工单、报表时使用对应模板。现在没有就不要创建这些路由。

## 9. 一页禁止出现

- 超过 2 个 Primary
- 6 种 Tag 色
- 3 种按钮高度、4 种圆角
- 10 个操作横排、Icon 风格混用
- 大面积渐变/阴影/高饱和底
- 同一状态不同页不同色，同一操作不同页不同钮
- 页面私有色板

---

## 10. 自检清单

- [ ] 页面类型与模板是否匹配，缺契约的块是否标了不做
- [ ] Primary Action 是否唯一，Primary 是否 ≤2
- [ ] Toolbar / Search / 表密度 / 行高是否统一
- [ ] 操作列是否 ≤3，Danger 是否红且二次确认
- [ ] 状态是否走五色语义
- [ ] 时间、数量对齐与格式是否统一，单号是否可点
- [ ] Loading / Empty / Error / Disabled / Ellipsis / Tooltip 是否完整
- [ ] 分页是否在右下，是否仍是游标而不是假页码
- [ ] 有勾选时是否有 BatchBar（仅已有批量能力）
- [ ] 长表是否固定关键列；长表单是否能找到提交
- [ ] 异常是否可识别且没有整页红
- [ ] 是否复用公共件、无硬编码色、无第二套视觉

任一项不合：先改，再交页面。
