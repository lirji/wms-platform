企业级作业台：GitHub 上还能抄的样子

上一轮是 Fiori / 曼哈顿 / 现代运维台。这一轮只看 GitHub 上星多、而且能直接对照壳层的开源后台。 仍不换信息架构，也不把 Ant 换成 shadcn / Element。只借 token：主色、侧栏、行高、按钮重量。

现在为什么不高级 青绿选中块 + 按钮投影 + 14px 圆角卡片 + KPI 六宫格，更像后台模板而不是执行席。顶栏按钮过多，主操作被「打开 PDA / 退出」稀释。
企业级作品在做什么 Fiori：压缩行高、对象页、工具条里只有一个实心主按钮。曼哈顿系：状态实心、数量等宽、命令贴单据。现代运维台：少阴影、细线、主按钮用墨色而不是第二品牌色。
建议先做哪套 「现代作业台」打底（去投影、表铺满、一颗主按钮），状态色跟「工业高对比」。Fiori 的 26px 控件只给桌面密表，不给 PDA。
